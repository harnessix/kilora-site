Install

Terminal

  1. Clone into ComfyUI/custom_nodes/:

    git clone https://github.com/harnessix/kilora ComfyUI/custom_nodes/kilora

  2. Install the requirements and restart ComfyUI:

    pip install -r ComfyUI/custom_nodes/kilora/requirements.txt

  3. Plain LoRA files stay in ComfyUI/models/loras/. Mods (.kmod.safetensors) go into ComfyUI/models/kilora/.

  4. Use KiLoRA LoRA Loader in place of the LoRA loader, and generate as usual.
