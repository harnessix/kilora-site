Creator guide

How to train a mod, how to turn a LoRA file into a mod, and what to check before you share one.

Train a mod

  1. Collect images that you own or have the rights to, or public-domain and CC0 images. Write one short caption per image.
  2. Train with the KiLoRA trainer, or with a supported outside trainer through its plugin (AI Toolkit or musubi-tuner).
  3. Render a strength sweep with a fixed prompt and seed: -1, 0, 0.5 and 1. Check that 0 matches the base model and that 1 shows your look.
  4. Fill in the manifest: name, license, base model, recommended strength and trigger words.
  5. Share the .kmod.safetensors file. People load it with KiLoRA Load Mod.
kilora-train --model <model folder> --data <image folder> --output my-mod.kmod.safetensors --id my-mod

Turn a LoRA file into a mod

You do not need to convert LoRA files to use them: KiLoRA reads them directly. To share a LoRA as a mod with a manifest, import it. Give a ComfyUI checkpoint file as --model. KiLoRA reads only its header and finds the model family from the key names.

kilora import style.safetensors --model <checkpoint file> --output style.kmod.safetensors

If the key names do not identify the family, add --family.

Before you share

  • Strip metadata from example images. ComfyUI writes the whole workflow into PNG files.
  • Name the training data and its license in the manifest and on the model page.
