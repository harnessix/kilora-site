Quick start

Install KiLoRA in ComfyUI, load one mod, and generate. This takes a few steps.

1. Install

Clone the repository into ComfyUI/custom_nodes/, install its Python packages, and restart ComfyUI. The commands are on the install page.

2. Add a mod

Put the mod file (.kmod.safetensors) into ComfyUI/models/kilora/. Then refresh ComfyUI.

3. Load it

  1. Load the base model with your usual loader. The mod names the base model that it was made for.
  2. Add KiLoRA Load Mod and connect the model.
  3. Pick the mod in file. Set strength to 1, and leave depth at -1 to use the depth that the mod recommends.
  4. Connect the model output to your sampler, and generate.

To see what the mod does, generate the same prompt and seed at strength 0 and at strength 1.
