Node reference

KiLoRA adds these nodes to ComfyUI. Find them under the KiLoRA entry of the node menu, or search by name. Each node shows the same text as a tooltip in ComfyUI.

You do not need most of them. A first workflow uses KiLoRA LoRA Loader in place of Load LoRA, or KiLoRA Load Mod for one mod file. The other nodes add control when you want it.

Main nodes

Loaders, settings, maps and tools. Most workflows need only one or two of these.

NodeWhat it does
KiLoRA Trigger WordsShows the trigger words of a LoRA file, from its metadata, its training tags and a Civitai sidecar.
KiLoRA Clear Local HistoryRemove the local history of applied chains.
KiLoRA Remove ModsRemoves all KiLoRA mods from a model.
KiLoRA Mod InfoShows the creator's hints for a mod: strength, trigger words, example prompt and depth.
KiLoRA Load ModLoads one KiLoRA mod into a copy of the model. Use it like a LoRA loader.
KiLoRA Depth ScheduleSets the depth of each block, also by sampling progress, from a list, a preset or an expression. Connect it to KiLoRA Apply Mod List.
KiLoRA Settings (Simple)KiLoRA settings with one choice: how the LoRAs mix. Connect it to the settings input of KiLoRA Apply or a KiLoRA LoRA node. The mix values: balanced: the defaults of KiLoRA Apply, with depth and routing from each mod. keep_each_strong: each token takes only its best LoRA, at full strength (routing scope token, routing select top1). subtle: one pass and one smooth blend per layer (depth 1, routing scope tensor, routing select sparsemax). stack: KiLoRA LoRA Loader does not route and gives the same output as Load LoRA. The other nodes use the balanced values for stack.
KiLoRA SettingsKiLoRA settings: a mix, and single values that replace the values of the mix. Connect it to the settings input of KiLoRA Apply or a KiLoRA LoRA node. Content keys default to per_expert; mix is the compatibility choice. Fused gate statistics are faster; torch reproduces images made before this release.
KiLoRA LoRA LoaderUse it in place of Load LoRA. It patches CLIP like Load LoRA. The model LoRAs of all chained KiLoRA LoRA Loaders are routed together when sampling starts. With mix set to stack, the output is the same as Load LoRA.
KiLoRA Route Loaded LoRAsPut it after your LoRA loaders. It takes the LoRAs that the loaders put on the model and routes them with KiLoRA. Each LoRA keeps its model strength. CLIP is not changed. If the LoRAs cannot be told apart, they stay as loaded and the report says so.
KiLoRA Route RecordRecords where each LoRA acts while the sampler runs. Connect its model to the sampler and its routes to KiLoRA Route Map.
KiLoRA Route MapShows where each LoRA acted in the last sampled image: one colored panel per LoRA, with a legend. Connect the routes of KiLoRA Route Record and the decoded image.
KiLoRA TimelineSets one value over the run: the strength of a mod, or when it is active, for example. Chain Timeline nodes to add rows, and connect the last one to KiLoRA Apply or the LoRA loader. The plot in the node shows every row.
KiLoRA Depth MapA depth per image area, from a mask (SAM2 and other segmenters) or an image (its brightness: depth, lineart or pose maps from ControlNet preprocessors). Until start, every area runs one depth, so the layout forms as usual. Then each area runs its own depth. Connect it to KiLoRA Apply or KiLoRA LoRA Loader.
KiLoRA LayerSelects the axes for this conditioning and sets its mask.
KiLoRA Layer FilterLimit added model function patches to one layer. Weight and object patches remain global.
KiLoRA LoRA LibrarySelect LoRAs at the first sampling step and save a recipe.
KiLoRA Similar LoRAsFind installed LoRAs with similar content features in the same base family.
KiLoRA Prepare LoRAsPrepare supported LoRA files and routing keys. Connect a model to prepare the selected mix in the listed order.
KiLoRA Mention PromptEncode a prompt in which @name calls a LoRA from the library. The mentions are removed before the text encoder and added to the mod list.

Mod list nodes

Build a list of mods and LoRAs, then apply the list in one node. Region, role and canvas nodes act on the whole list.

NodeWhat it does
KiLoRA Mod List: Add ModAdds one mod to a mod list. Chain several, then connect the list to KiLoRA Apply Mod List.
KiLoRA Mod List: Add LoRAAdds a plain LoRA file to a mod list.
KiLoRA PaletteLoads a saved palette (LoRA and mod files with strengths, roles and trigger words) as a mod list. Shuffle picks a different set for each seed.
KiLoRA Save PaletteSaves a mod list as a palette file without weights, for example a Shuffle pick.
KiLoRA Mod List: Suggest LoRAsLists installed LoRAs by co-usage or embedding similarity.
KiLoRA Mod List: CheckShows the load order and any problems. The model is not changed.
KiLoRA Apply Mod ListLoads all mods of a mod list into a copy of the model.
KiLoRA Mod List: RegionLimits the mods of a mod list to the masked area of the image. Each mod chooses its experts from that area. Chain lists with different masks to place mods in different areas.
KiLoRA Mod List: Region AttentionExperimental. Keeps the change of each KiLoRA region inside its region. In a window of sampling after the layout forms, the tokens of a region attend less (soft) or not at all (hard) to tokens outside it. Connect it after KiLoRA Apply.
KiLoRA Mod List: Token RolesSets which tokens the mods of a mod list change in an editing workflow: the target image, the reference images or the text. Other tokens keep the base weights.
KiLoRA Mod List: Two PanelsMarks a two-panel canvas. One panel holds the reference picture and the other is the image being made. Mods on auto roles change only the target panel. Applies to every mod of the list.
KiLoRA Mod List: Region IsolationExperimental. Keeps the area outside the KiLoRA regions as the base model makes it. In the first part of sampling, a base-only branch runs next to the sampler, and the outside follows it. Each step in that part costs one extra model call. Connect it after KiLoRA Apply.
KiLoRA Save RecipeSaves a mod list and settings as references without copying the weights.
KiLoRA Direction NodesAdd direction nodes from a stored library basis.

Live mode nodes

Record and write around the sampler, with undo, saves and export. Experimental.

NodeWhat it does
KiLoRA Live: Undo, Reset, SaveUndo, reset, save points and loading for a live mod.
KiLoRA Live: SettingsTurns learning on or off, and sets the learning speed.
KiLoRA Live: Editor PacksLists the installed editor packs, turns packs on or off, and shows the packs of the loaded save.
KiLoRA Live: Freeze as Static ModSaves the live mod's current state as a new static mod.
KiLoRA Live: Export for SharingSaves a live mod for sharing. By default without what it learned from you.
KiLoRA Live: 1. Record (before sampler)Put before the sampler to record a live mod or imported LoRAs, even without a live mod.
KiLoRA Live: 2. Write (after sampler)Live mode, step 2. Put it after the sampler. The editor updates the live mod. You can undo it. A guard refuses a write that lowers prompt following or collapses the image. Without the CLIP on Record, the guard is off.
