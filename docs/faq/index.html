FAQ

Short answers. If your question is not here, ask in the code repository's Discussions.

Is a mod a LoRA?

It is LoRA-style: small changes on a frozen base model. A mod is its own file type, so it loads through the KiLoRA nodes, not a plain LoRA loader.

Can I use my LoRA files as they are?

Yes. Add them with KiLoRA Mod List: Add LoRA or KiLoRA LoRA Loader. KiLoRA reads the usual key forms: ComfyUI, kohya, Diffusers and PEFT.

Can I get the same image as the stock LoRA loader?

Yes. Set mix to stack in KiLoRA Settings (Simple). Each LoRA then runs as a plain LoRA, and the result is the stock result.

What hardware do I need?

What your base model needs. KiLoRA adds a small amount of work per layer, and GGUF and fp8 models keep their memory size.

Which base models work?

Anima and FLUX.3 Klein are verified on GPU. Other families are CPU-tested or experimental. The table is on the home page.

Do my images leave my computer?

No. Everything runs locally.

Can a mod file run code?

No. A mod file is a standard safetensors file with numbers, example images and a short description.
