Mod file format

A mod is one file. It holds numbers, example images and a short description. It holds no code.

File name

A mod file is named <mod id>.<base model>.kmod.safetensors, for example my-style.zimage.kmod.safetensors. The short ending .kmod also works. Put mod files in ComfyUI/models/kilora/.

What is inside

PartWhat it is
WeightsThe trained numbers of the mod, as standard safetensors tensors
Example imagesSmall example images, stored inside the file
ManifestA short description in the file header: name, base model, license, recommended strength, trigger words

No code

The file is a standard safetensors file. Any safetensors reader can open it. KiLoRA never runs code from a mod file and never unpickles it.

Other tools

  • The file header also carries the common model-card fields (title, author, license, trigger words), so model sites can show the basics.
  • A plain LoRA loader finds nothing it knows in a mod file. It changes nothing, so it cannot apply a mod the wrong way. Use the KiLoRA nodes.
  • Saving the same mod again gives the same bytes. Model sites can find a file by its hash.

Main manifest fields

FieldExample
idmy-style
nameMy Style
licenseThe creator's choice, for example CC-BY-4.0
base_modelThe base model family, for example Z-Image

The full field list is in the code repository: docs/mod-format.md.
