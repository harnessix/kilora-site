Mods trained on PD12M

Some KiLoRA mods are trained on PD12M, the Public Domain 12M image-text dataset.

PartLicenseWhat it means for a mod
PD12M imagesCC0 1.0, or the Public Domain MarkNo copyright restrictions on the training images
PD12M metadata (captions and other fields)CDLA-Permissive-2.0The license puts no restriction or obligation on results, and a trained model is such a result

Attribution we give

Trained on images from PD12M (Public Domain 12M), CC0 and Public Domain Mark images, with metadata under CDLA-Permissive-2.0.

Dataset paper: "Public Domain 12M: A Highly Aesthetic Image-Text Dataset with Novel Governance Mechanisms". Neither license requires this credit for a trained mod. We give it so that you know where the training data came from.

If you share the dataset's metadata itself, CDLA-Permissive-2.0 requires that you include the license text with it. A mod file does not contain the metadata.

Your own mods

  • Choose a license and write it into the mod's manifest.
  • Train only on images that you own or have rights to, or on public-domain and CC0 images.
  • A learned state comes from your own generations. Saves hold the learned state, never the images. Export for Sharing leaves the learned state out unless you include it. Choose the license of a mod with a learned state like that of any mod you share.
