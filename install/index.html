Install

KiLoRA runs in ComfyUI. Install it from GitHub.

ComfyUI

Install from GitHub

git clone https://github.com/harnessix/kilora ComfyUI/custom_nodes/kilora

Then install its Python packages with the Python that runs ComfyUI, and restart ComfyUI:

python -m pip install -r ComfyUI/custom_nodes/kilora/requirements.txt

Mods go in ComfyUI/models/kilora/, not in models/loras/Source on GitHub

Put mod files (.kmod.safetensors) into ComfyUI/models/kilora/. Plain LoRA files stay in ComfyUI/models/loras/.

Load one mod

  1. Load the base model with your usual loader.
  2. Add KiLoRA Load Mod and connect the model.
  3. Pick the mod in file and set strength: 1 is the trained strength, 0 is off, below 0 pushes away from the mod. The range is -2 to 2.
  4. Leave depth at -1 to use the depth that the mod recommends.
  5. Connect the model output to your sampler.

KiLoRA Mod Info reads the creator's hints from a mod: the recommended strength, trigger words and an example prompt.

Requirements

Static mods need what the base model needs, plus the mod file.

KiLoRA

Keyed, Iterative and Composable Low-Rank Adaptation. Made by harnessix.

Example mods are trained on PD12M: CC0 and Public Domain Mark images, with metadata under CDLA-Permissive-2.0.
